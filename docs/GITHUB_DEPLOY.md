# Автоматическое обновление сервера из GitHub

Workflow `.github/workflows/deploy-server.yml` отправляет изменения ветки `dev` на сервер `157.228.134.245` и выполняет `docker compose up -d --build`. Его также можно запустить вручную через вкладку **Actions** в GitHub.

Для подключения используется отдельный SSH-ключ `DEPLOY_SSH_KEY`. Его публичная часть установлена на сервере для пользователя `crmdeploy`; ключ разрешает только команду деплоя. В workflow исходники передаются архивом, а `.env*`, локальные зависимости и результаты сборки в архив не попадают. На сервере переменные окружения и Docker volumes сохраняются.

## Добавить секрет в GitHub

В Git Bash выполните вход в GitHub CLI один раз:

```bash
gh auth login
```

Затем добавьте приватный ключ как секрет репозитория. Команда читает ключ из файла напрямую, поэтому его не нужно вставлять в чат или показывать в терминале:

```bash
gh secret set DEPLOY_SSH_KEY --repo Aksenov-m/crm < .deploy-local/github-deploy-key
```

После добавления секрета workflow сможет деплоить новые коммиты из `dev`. Статус и журнал сборки доступны в **GitHub → Actions**.
