# Поток — демо CRM для Авито

Одностраничное приложение по `SPEC.md`: от фотографии и описания товара до объявления, диалога с покупателем и продажи.

## Запуск

Нужен Node.js 22.20 или новее. В PowerShell:

```powershell
npm.cmd install
npm.cmd run dev
```

Откройте http://127.0.0.1:3000. `.cmd` позволяет запускать npm при ограничениях PowerShell Execution Policy.

Для production-сборки:

```powershell
npm.cmd run build
npm.cmd start
```

В macOS/Linux используйте `npm` вместо `npm.cmd`.

## Деплой в Timeweb Cloud

Для текущей демоверсии подходит **Frontend → Next.js без SSR**: серверные API отсутствуют, данные сохраняются в браузере. Настройки приложения:

| Поле | Значение |
| --- | --- |
| Node.js | 22, версия 22.20 или новее |
| Команда сборки | `npm run build` |
| Директория сборки | `out` |
| Путь до директории проекта | Оставить пустым, если `package.json` в корне репозитория |
| Переменная окружения для сборки | `NEXT_OUTPUT=export` |

Переменная `NEXT_OUTPUT=export` включает статический экспорт: после сборки создаётся `out/index.html` и ресурсы сайта. Команда запуска для этого режима не нужна. Без этой переменной Next.js создаёт обычную сборку в `.next`, которую нельзя использовать как директорию статического сайта.

Для локальной проверки статической сборки в PowerShell:

```powershell
$env:NEXT_OUTPUT = "export"
npm.cmd run build
Remove-Item Env:NEXT_OUTPUT
```

Если приложение в Timeweb уже создано **с поддержкой SSR**, не задавайте `NEXT_OUTPUT`. Используйте сборку `npm run build` и запуск `npm start`. Сервер слушает `0.0.0.0`; порт задаётся переменной `PORT`, по умолчанию — `3000`. Порт в настройках платформы должен совпадать с портом приложения. После статической сборки перед `npm start` выполните обычную сборку без `NEXT_OUTPUT`.

Сборка требует установки devDependencies (TypeScript и Tailwind). Не используйте `npm install --omit=dev` на этапе сборки. Перед повторным деплоем отправьте изменения в репозиторий и убедитесь, что Timeweb собирает нужную ветку и коммит.

Документация: [Next.js в Timeweb](https://timeweb.cloud/docs/apps/deploying-frontend-apps/nextjs), [настройки frontend-приложений](https://timeweb.cloud/docs/apps/deploying-frontend-apps), [статический экспорт Next.js](https://nextjs.org/docs/app/guides/static-exports).

## Что попробовать

1. Нажмите **Добавить товар**, загрузите JPEG/PNG/WebP до 5 МБ, добавьте описание, цену и категорию. Или нажмите **Попробовать на примере**.
2. **Сгенерировать объявление** создаёт локальный шаблон на основе вашего текста. Заголовок и описание можно исправить перед добавлением.
3. Перетаскивайте товар по пяти колонкам. На телефоне или с клавиатуры этап выбирается в меню в правом нижнем углу карточки; также доступен внутри карточки и в списке объявлений.
4. В **Покупателях** создайте контакт, привяжите товар, добавьте заметку и выберите статус: Новый, Переговоры, Продажа или Отказ.
5. В **Сообщениях** выберите диалог и отправьте текст. **Получить сообщение** создаёт локальное входящее сообщение. В колокольчике можно создать уведомление и перейти к нему.
6. Переместите товар в **Продан** — выручка и аналитика изменятся. Обратное перемещение убирает его из выручки. Статусы покупателей управляются отдельно от этапов товаров.
7. Кнопка **Обновить демо-статистику** прибавляет 12 просмотров и одно добавление в избранное каждому товару на этапе «На Авито».

## Ограничения демо

- Нет бэкенда, базы данных, API и подключения к Авито. Публикации и сообщения никогда не отправляются наружу.
- Генерация — текстовый шаблон, без AI-сервиса и распознавания фотографии.
- Изменения сохраняются в localStorage этого браузера (`avito-crm-demo:v1`). Нет синхронизации между устройствами. При запрете или переполнении хранилища приложение показывает предупреждение.
- Фотографии сжимаются в браузере до 1200 px. Демонстрационные фото включены в `public/products`; приложение не обращается за ними во внешнюю сеть.
- Аналитика строится по локальным товарам: выручка — сумма цен проданных, конверсия — доля проданных среди всех товаров.
- Начальная страница рендерится Next.js в HTML при сборке; после загрузки вся работа идёт на клиенте. API routes и server actions отсутствуют.

Чтобы вернуться к исходным примерам, удалите только ключ `avito-crm-demo:v1` в хранилище сайта через инструменты браузера и перезагрузите страницу.

## Проверки и структура

```powershell
npm.cmd run typecheck
npm.cmd test
npm.cmd run test:e2e
```

Для браузерных тестов нужен установленный Google Chrome. Конфигурация использует отдельный тестовый профиль и локальный сервер; данные обычного профиля не меняются. Скриншоты сценариев сохраняются в `artifacts/ui`.

- `src/app` — страница, макет, стили Next.js + Tailwind CSS.
- `src/components` — доска, редактор товара, покупатели, сообщения, аналитика.
- `src/lib/crm.ts` — модель, исходные данные, mock-генерация, расчёты и проверка сохранённых данных.
- `tests/crm.test.ts` — тесты бизнес-логики.
- `tests/app.spec.ts` — пользовательские сценарии в браузере, мобильный экран и проверка отсутствия внешних HTTP-запросов.

Официальные руководства: [Next.js](https://nextjs.org/docs/app/getting-started/installation), [Tailwind CSS](https://tailwindcss.com/docs/installation/framework-guides/nextjs).
